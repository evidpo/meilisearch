## Meilisearch (Backend)

| Статус | Функция | Описание |
|--------|---------|----------|
| ✅ | Индекс courses | 8060 документов, ~5ms ответ |

## n8n Workflow (Синхронизация)

| Статус | Функция | Описание |
|--------|---------|----------|
| ✅ | Загрузка из Directual | API endpoint courses_for_meilisearch |
| ✅ | Transform полей | Маппинг Directual → Meilisearch |
| ✅ | Добавление/обновление | POST /indexes/courses/documents |
| ✅ | Удаление УПРАЗДНЕНО | Batch delete по direction_of_study |
| 🔴 | Cron триггер | Ежедневное обновление |
| 🟡 | Логирование ошибок | Уведомления при сбоях |
| 🟢 | Инкрементальная синхронизация | Только изменённые курсы |

## Виджет поиска (Frontend)

### Основной функционал

| Статус | Функция | Описание |
|--------|---------|----------|
| ✅ | Полноэкранный оверлей | Открытие по клику на кнопку |
| ✅ | Поле поиска | С иконкой и кнопкой очистки |
| ✅ | Debounce 250ms | Задержка перед запросом |
| ✅ | Мгновенные результаты | Поиск при вводе |
| ✅ | Кнопка "Найти" | Принудительный поиск |
| ✅ | Закрытие по Escape | И по кнопке "Закрыть" |
| ✅ | Блокировка скролла | body overflow: hidden |
