# Ограничения и особенности

⚠️ **Прочитай перед любыми изменениями!**

---

## 🚨 Критические ограничения

### 1. Creatium — Custom HTML блок

```javascript
❌ НЕ РАБОТАЕТ:
- ES6 modules (import/export)
- Внешние npm-пакеты
- Сборщики (webpack, vite)

✅ РАБОТАЕТ:
- Vanilla JS (ES5/ES6)
- Inline CSS
- CDN библиотеки через <script>
- IIFE для изоляции
```

**Причина:** Creatium вставляет HTML как есть, без сборки.

---

### 2. Meilisearch API — только Search Key

```javascript
❌ НЕ ИСПОЛЬЗУЙ в браузере:
const MASTER_KEY = '16mx5lg...';  // ОПАСНО!

✅ ИСПОЛЬЗУЙ:
const SEARCH_KEY = 'b17c514...';  // Только чтение
```

**Search Key позволяет:**
- Поиск документов
- Чтение facets
- НЕ позволяет редактировать индекс

---

### 3. CORS — Meilisearch (self-hosted за Traefik)

```
✅ Meilisearch по умолчанию разрешает CORS
✅ Запросы из браузера (search.evidpo.ru) работают

⚠️ Если будут проблемы:
- Проверить лейблы Traefik / заголовки
- Использовать прокси через n8n
```

---

### 4. Синхронизация — Directual пагинация

```javascript
⚠️ ПРОБЛЕМА:
Directual API по умолчанию возвращает max 100 записей

✅ РЕШЕНИЕ:
В n8n workflow использовать пагинацию:
- pageSize=100
- Цикл по страницам
- Или увеличить лимит в Directual endpoint
```

**Текущий статус:** 8060 курсов загружается корректно

---

### 5. Удаление курсов — УПРАЗДНЕНО

```javascript
ЛОГИКА:
if (course.direction_of_study === 'УПРАЗДНЕНО') {
  // Удалить из Meilisearch
  // НЕ добавлять в активные
}

⚠️ ВАЖНО:
- Удаление происходит в n8n workflow
- Batch delete по массиву ID
- После удаления курс НЕ появится в поиске
```

---

### 6. Изображения курсов

```javascript
ИСТОЧНИК: Directual поле pic1
ФОРМАТ: URL (https://...)

⚠️ ПРОБЛЕМЫ:
- Некоторые курсы без картинок
- Картинки могут быть большими

✅ РЕШЕНИЕ:
- Fallback на placeholder
- object-fit: cover для обрезки
- Lazy loading (loading="lazy")
```

---

### 7. Категории — динамические

```javascript
ЛОГИКА:
1. Запрос всех курсов (limit: 1000)
2. Агрегация students по direction
3. Сортировка по сумме students DESC
4. Топ-10 для категорий
5. Топ-4 для "Часто ищут" (через маппинг)

⚠️ ВАЖНО:
- Категории обновляются при открытии оверлея
- Один HTTP запрос на обе секции
- Маппинг directionToQuery — статичный в коде
```

---

### 8. Маппинг направлений → запросы

```javascript
const directionToQuery = {
  'Первая помощь': 'первая помощь',
  'Автошколы': 'автошкола',
  'БДД': 'безопасность дорожного движения',
  // ...
};

⚠️ ОГРАНИЧЕНИЕ:
- Новые направления НЕ добавятся автоматически
- Покажутся как lowercase названия
- Для кастомного текста — добавить в маппинг вручную
```

## 🔄 Workarounds

### Проблема: Курс не появляется в поиске
```
1. Проверить direction_of_study !== 'УПРАЗДНЕНО'
2. Запустить n8n workflow
3. Проверить Meilisearch Dashboard
```

### Проблема: Категория не отображается
```
1. Проверить что есть курсы с этим direction
2. Проверить students > 0 для курсов
3. Категория должна быть в топ-10 по students
```

### Проблема: Картинка не загружается
```
1. Проверить pic1 в Directual
2. URL должен быть https://
3. Проверить CORS на источнике картинки
```
