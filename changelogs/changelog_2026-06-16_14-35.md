# Changelog 2026-06-16_14-35

## Миграция Meilisearch: Railway → self-hosted на VPS evidpo

### 🎯 Что сделано

Поисковый движок Meilisearch v1.9 перенесён с платного Railway на собственный сервер
evidpo (31.128.43.138) — отдельным Docker-контейнером за Traefik с TLS от Let's Encrypt.
Все 8060 документов, настройки индекса и 9 групп синонимов скопированы 1:1 по API без
даунтайма; виджеты переключены на новый адрес `https://search.evidpo.ru` с новым
read-only Search Key. Railway пока работает параллельно и будет погашен после периода
стабильной работы.

---

### 🔄 Изменения

**Инфраструктура (сервер evidpo):**
- Сгенерирован новый `MEILI_MASTER_KEY`, добавлен в `/root/.env` (в репозиторий не коммитится)
- В `/root/docker-compose.yml` добавлен сервис `meilisearch` (`getmeili/meilisearch:v1.9`,
  `MEILI_ENV=production`, том `${DATA_FOLDER}/meili_data`, сеть `root_default`)
- Traefik-роутер: Host `search.evidpo.ru`, TLS, certresolver `mytlschallenge`, порт 7700
- DNS: добавлена A-запись `search.evidpo.ru → 31.128.43.138`
- Сделаны бэкапы `docker-compose.yml` и `.env`

**Данные:**
- Индекс `courses` создан заново, settings зеркалированы с Railway (searchable/filterable/
  sortable/displayed + синонимы + typoTolerance + rankingRules)
- Перелито 8060 документов постранично (по 1000) через API
- Сгенерирован новый read-only Search Key (actions=`search`, index=`courses`)

**Фронтенд (виджеты):**
- `MEILI_HOST` → `https://search.evidpo.ru`, `MEILI_KEY` → новый search-key
  в `evidpo-search-overlay.html` и `evidpo-recommendations.html`

**Документация:**
- Обновлены host, ключи, число документов (201 → 8060), реальные настройки индекса
- Старый master key убран из доков; старый search key заменён на новый
- Раздел Railway в `meilisearch-setup.md` помечен как архивный
